# Plinnth Desktop

Public desktop installers for [Plinnth](https://plinnth.com).

[Download for Windows, macOS and Linux](https://plinnth.com/downloads) · [User guide](https://plinnth.com/docs)

This repository contains release notes and downloadable installers. The application source is maintained separately.

The desktop workbench includes a project/file explorer, document tabs, native menus, local calculation files, optional cloud projects, and the 32-calculator catalogue. Basic includes three calculators and local saving; Plus and Pro access follows your connected account.

Current releases are previews. Windows and macOS installers do not yet have trusted publisher signing or Apple notarization, so the operating system may warn or block installation. Updates are installed manually. Back up your local library before upgrading.

Choose Windows x64, macOS Apple Silicon or Intel, or Linux x64 (AppImage or Debian). Compare installer hashes against SHA256SUMS.txt attached to each release. On a phone or tablet, use the web workspace.
